ЗАВДАННЯ 2 (SQL, Напрямок 2 -- Data Whisperer):

Ти отримуєш схему бази даних SQLite інтернет-магазину та завдання.
Напиши ОДИН SQL-запит, що розв'язує завдання.
У відповіді поверни лише SQL-запит у блоці коду -- без пояснень, коментарів чи додаткового тексту.

СХЕМА БАЗИ ДАНИХ:
CREATE TABLE customers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    city TEXT,
    registered_at TIMESTAMP
);
CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    price NUMERIC(10,2) NOT NULL,
    stock INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT 1
);
CREATE TABLE orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    customer_id INTEGER REFERENCES customers(id),
    created_at TIMESTAMP NOT NULL,
    status TEXT DEFAULT 'completed'
);
CREATE TABLE order_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id INTEGER REFERENCES orders(id),
    product_id INTEGER REFERENCES products(id),
    quantity INTEGER NOT NULL,
    unit_price NUMERIC(10,2) NOT NULL
);

ЗАВДАННЯ:
Для кожної категорії товарів (products.category) визначити ОДИН товар з
найбільшою сумарною виручкою серед завершених замовлень (orders.status =
'completed') за період з '<START_DATE>' по '<ANCHOR_DATE>' включно
(за полем orders.created_at).

Уточнення (обов'язково дотримуйся):
- Виручка товару = сума (order_items.quantity x order_items.unit_price)
  за всіма позиціями цього товару в межах зазначеного періоду.
- Якщо в категорії кілька товарів мають однакову максимальну виручку --
  виведи той, чий products.id менший (стабільний tie-break).
- Категорія визначається через products.category.
- Вивести РІВНО ОДИН рядок на кожну категорію, представлену в замовленнях
  за цей період: категорія, назва товару, сумарна виручка.
- Відсортувати за назвою категорії за зростанням (алфавітно).

Формат виводу -- рівно 3 стовпці в такому порядку: категорія, назва товару,
сумарна виручка.
