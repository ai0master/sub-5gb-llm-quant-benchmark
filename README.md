Nonlinearity of quantization and task dissociation in local LLMs up to 5 GB (Нелінійність квантування та дисоціація задач у локальних LLM обсягом до 5 ГБ)

A task-driven benchmark and evaluation protocol for selecting local, GGUF-quantized LLMs that run within a 5 GB memory budget on CPU-only machines — with Ukrainian-language educational deployment as the motivating (but not limiting) use case. Companion repository for the paper prepared for CSIT 2026.

Pепозиторій містить промпти, тестові гарнеси (SQLite/pytest/mutation testing) та сирі результати тестування 18 локальних GGUF-моделей (≤5GB) на трьох кластерах задач — креативне письмо, SQL, генерація Python-коду — для статті на конференцію CSIT 2026
