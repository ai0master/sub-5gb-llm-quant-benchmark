Ти отримуєш схему бази даних SQLite інтернет-магазину та завдання.
Напиши ОДИН SQL-запит, що розв'язує завдання.
У відповіді поверни лише SQL-запит у блоці коду — без пояснень, коментарів чи додаткового тексту.

СХЕМА БАЗИ ДАНИХ:
CREATE TABLE customers (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    city TEXT,
    registered_at TIMESTAMP
);
CREATE TABLE products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    price NUMERIC(10,2) NOT NULL,
    stock INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT 1
);
CREATE TABLE orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    customer_id INTEGER REFERENCES customers(id),
    created_at TIMESTAMP NOT NULL,
    status TEXT DEFAULT 'completed'
);
CREATE TABLE order_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id INTEGER REFERENCES orders(id),
    product_id INTEGER REFERENCES products(id),
    quantity INTEGER NOT NULL,
    unit_price NUMERIC(10,2) NOT NULL
);

ЗАВДАННЯ:
Визначити топ-5 міст за загальною виручкою від завершених замовлень
(orders.status = 'completed') за останні 30 днів. Вважай поточною датою
'<ANCHOR_DATE>' (тобто період — з '<START_DATE>' по '<ANCHOR_DATE>' включно,
за полем orders.created_at). (<ANCHOR_DATE> = '2026-07-21', <START_DATE> = '2026-06-22')

Уточнення (обов'язково дотримуйся):
- Виручка одного замовлення = сума (order_items.quantity × order_items.unit_price)
  за всіма його позиціями.
- "Кількість замовлень" міста = кількість УНІКАЛЬНИХ замовлень (не позицій товару),
  що підпадають під умову.
- Місто визначається через customers.city (customers.id = orders.customer_id).

Формат виводу — рівно 3 стовпці в такому порядку: місто, кількість замовлень,
загальна виручка. Відсортувати за загальною виручкою за спаданням.
Вивести не більше 5 рядків.
